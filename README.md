# Customer Churn Analysis Using Python

## 📌 Project Overview
This project analyzes customer churn data using Python. It includes data cleaning, preprocessing, handling missing values, exploratory data analysis (EDA), and data visualization to identify customer behavior and generate business insights.

## 📂 Dataset
- Telco Customer Churn Dataset
- Format: CSV

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔄 Project Workflow
1. Data Loading
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Business Insights

## 📊 Key Analysis
- Churn Distribution
- Customer Demographics
- Tenure Analysis
- Monthly Charges Analysis
- Contract Type Analysis
- Payment Method Analysis

## 📁 Files
- customer churn Project.ipynb
- WA_Fn-UseC_-Telco-Customer-Churn.csv
- Summary of Customer Churn Analysis.pdf

## 🎯 Objective
To understand customer churn patterns and provide actionable business insights using Python.
